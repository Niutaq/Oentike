# Cel Projektu: ZT-FinGate (Zero-Trust Financial Gateway & Approval Engine)

## 1. Koncepcja Główna
Połączenie inteligentnego systemu akceptacji wydatków (LLM + BPM) z architekturą Zero-Trust Edge. System nie tylko procesuje biznesowe żądania finansowe (FinTech/Approval), ale zabezpiecza je na poziomie sieciowym (Rust/eBPF) i dokładnie monitoruje koszty operacyjne (FinOps). 

To hybryda, która łączy Twoje wcześniejsze pomysły (n8n, LLM, NATS, Go) z nowymi wymogami 2026 (Rust, CyberSec, Zero-Trust, Edge).

## 2. Architektura Systemu

### A. Data Plane / Edge Agent (Rust) - [Mobile / Chmura Prywatna]
*   **Zadanie:** Bezpieczny punkt wejścia do systemu. Aplikacja/Agent przechwytujący żądania od użytkowników.
*   **Sieci / CyberSec:** Szyfrowanie mTLS, opcjonalnie filtrowanie ruchu przez eBPF, uwierzytelnianie (SPIFFE). Ruch poza tunelem jest odrzucany.
*   **FinOps:** Agent na bieżąco zbiera i wysyła metryki (CPU, RAM, obciążenie sieci) do systemu centralnego, aby śledzić koszt każdej transakcji (Chargeback).

### B. Control Plane / Core Services (Go)
*   **Zadanie:** Serce biznesowe i sieciowe systemu, podzielone na mikroserwisy.
*   **Relay API (Go):** Odbiera zaszyfrowany ruch od agentów w Rust, waliduje tokeny (Keycloak) i publikuje eventy.
*   **Approval & FinOps Service (Go):** Silnik reguł (BPM). Ocenia wnioski wyciągnięte przez AI i sprawdza z budżetami (np. czy zakup instancji AWS na 1000$ mieści się w limitach działu IT).
*   **Komunikacja:** Całość spięta szybkimi kolejkami **NATS JetStream** (event sourcing, replay).

### C. Analiza AI & Ekstrakcja
*   **Zadanie:** Procesowanie np. rachunków, maili, faktur zrzuconych przez agenta Edge.
*   **Workflow:** N8n odbiera event -> przekazuje do LLM (tylko jedna rola: ekstrakcja: kategoria, kwota, sprzedawca, priorytet) -> zwraca ustandaryzowany JSON do NATS.

## 4. CNCF & Obserwowalność (Klucz do ról Ops/DevSecOps)
Cały pipeline, od urządzenia brzegowego w Rust, aż po bazy danych w Go, jest śledzony za pomocą **OpenTelemetry**.
*   **Tracing:** Tempo (Widzisz dokładnie ile ms zajęło szyfrowanie w Rust, a ile zapytanie LLM).
*   **Metryki:** Prometheus + Grafana (Biznesowe dashboardy: "Czas akceptacji kosztów", "Koszt infrastruktury per zapytanie").
*   **Logi:** Loki.

## 5. Korzyści rynkowe (Monachium, Azja, Globalnie)
1. **Dev:** Go + Rust to elita backendowa.
2. **Sec:** Zero-Trust (mTLS) i izolacja ruchu pokazują dojrzałość w myśleniu o bezpieczeństwie (kluczowe w FinTech / Automotive).
3. **Net:** Zastosowanie NATS, Load Balancingu, koncepcji Edge Computing.
4. **Ops / FinOps:** Kompleksowe opomiarowanie systemu (OpenTelemetry), konteneryzacja (Docker/Distroless), śledzenie kosztów własnych chmury.

## 6. Kolejne Kroki (Roadmapa wykonawcza)
