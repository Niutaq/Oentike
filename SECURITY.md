# Security Policy

## Reporting a Vulnerability

If you discover a security issue in Oentike, please report it privately via [GitHub Security Advisories](https://github.com/Niutaq/Oentike/security/advisories/new) or email the maintainer directly.

**Do not open a public issue for security vulnerabilities.**

## Scope

- API (gRPC/HTTP) input handling and data integrity
- Atlas pack signature verification
- Expedition journal local data storage
- Tauri desktop shell security (CSP, capabilities, ACL)

## Response

We aim to acknowledge reports within 48 hours and provide a fix or mitigation plan within 7 days.
